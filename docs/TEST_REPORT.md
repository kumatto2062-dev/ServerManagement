## 制約

- サーバーへ常時接続するBotは使用しません。参加・退出の名簿更新は取得ボタンを押した時点です。
- 月末の自動取得や、入力なしの自動キックはありません。
- ロール付き招待の有効期限・削除・付与ロール設定はDiscordで行います。URL保存だけで招待設定は変わりません。
- 無料枠には1日のリクエスト数、1回のCPU時間、外部通信回数等の上限があります。
- 一度の転送リクエストで1人を処理します。大きい名簿と長期間の履歴はFirebaseの転送量やCPU時間へ影響します。
- 10分を超えたプランは再開せず、新しく変更確認します。
- Discord操作を開始した後にエラーが出た場合は、一部のロール変更が済んでいる可能性もあるため「要確認」で止めます。参加状態取得で確認してから新しいプランを作成します。
- 旧Botを併用せず、移行時にCtrl+Cで停止してください。
- 永続履歴とプランの自動削除はありません。増大した場合はバックアップして整理が必要です。
